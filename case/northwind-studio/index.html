Northwind Studio

A quiet, image-led website for an architecture and interiors studio.

Concept project for a fictional brand, made by Vividoro to show our range. Photography from Unsplash contributors.

The brief

An architecture studio needs a site where the buildings lead. Minimal chrome, generous space, and project pages that read like a short story.

Our approach

A full-width hero photograph sets the tone, with an elegant serif headline over it. Project tiles keep the grid simple, and the mobile project page puts the essentials (area, materials, status) in a quiet table so the images stay the focus.

What we made

  • Homepage with full-bleed hero
  • Selected projects grid
  • Project detail page (mobile)
  • Services strip
